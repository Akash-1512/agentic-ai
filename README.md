# Agentic AI Engineering — From Beginner to Advanced

11-week structured journey to become a production Agentic AI Engineer.
Building in public. Daily commits. One major capstone project.

## Plan

- **Phase 1 — Foundations** (Weeks 1-2): Advanced Python, PyTorch essentials
- **Phase 2 — LLMs & Transformers** (Weeks 3-4)
- **Phase 3 — RAG & Vector Databases** (Weeks 5-6)
- **Phase 4 — Agentic AI: LangChain & LangGraph** (Weeks 7-8)
- **Phase 5 — Production + Infrastructure** (Weeks 9-10)
- **Phase 6 — Advanced + Interview Prep** (Week 11)

## Capstone — AgentForge

Building from Week 5 onward. Multi-agent research platform with RAG,
LangGraph orchestration, MCP tools, RAGAS evaluation, Langfuse
observability, Kubernetes deployment.
